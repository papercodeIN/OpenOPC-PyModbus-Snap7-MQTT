# Contributing

Thanks for contributing!

- Keep examples runnable with `pip install -r requirements.txt`.
- Don't commit `.ipynb_checkpoints/`, `*.exe`, `*.7z`, or secrets.
- Use `kebab-case` for new files; avoid spaces and `&` in filenames.
- For Windows-only OPC-DA examples, note OS/bitness in the header.
- Open a PR against `main` with a clear description and test steps.
