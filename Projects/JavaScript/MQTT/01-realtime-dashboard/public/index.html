Advanced — connect over WebSocket from the browser
How the connection is made. TCP keeps the MQTT connection in this local Node.js service (port 1883, or 8883 with TLS) and streams messages to the page — every broker works, including those without a WebSocket listener. WebSocket connects from the browser itself and needs a broker WebSocket listener (for example 9001); browsers only accept wss:// with a certificate the operating system trusts.
Credentials. In TCP mode the username and password are sent to this local service over loopback and held in memory only for the lifetime of the connection — never written to disk, never logged. In WebSocket mode they stay in this tab. Use an account with read-only access to the configured topics.
