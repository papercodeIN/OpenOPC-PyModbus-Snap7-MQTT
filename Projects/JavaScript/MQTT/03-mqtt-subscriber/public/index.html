SCOPE

What it does

Subscribes only — it never publishes. Messages are kept in memory for the current service session and are lost when the service stops. The service binds to 127.0.0.1 unless HTTP_HOST says otherwise.

Only subscribe to brokers and topics you are authorized to access. Payloads may contain sensitive data — the inspector shows them to anyone who can open this local page.
