# BACnet-Python

A collection of Python tools for discovering, simulating, and integrating BACnet/IP devices.

## Projects

| Project | Description |
|---|---|
| [BACnet Device Discover](https://github.com/fusion-automate/BACnet-Python/tree/main/BACnet_Device_Discover) | Discover BACnet/IP devices, inspect their objects and properties, read live values, and write supported properties from a browser-based console. |
| [BACnet Device Simulator](https://github.com/fusion-automate/BACnet-Python/tree/main/BACnet_Device_Simulator) | Run a configurable BACnet/IP device with simulated points, live values, commandable objects, and a web dashboard—without physical hardware. |
| [BACnet <-> MQTT Bridge](https://github.com/fusion-automate/BACnet-Python/tree/main/BACnet%20%2B%20MQTT) | Connect BACnet/IP devices to an MQTT broker with bidirectional value publishing, commands, discovery, point mapping, and a web console. |
