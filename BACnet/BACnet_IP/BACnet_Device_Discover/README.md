# BACnet Device Discover

This project provides a Python script (`bacnet_device_discover_01092025.py`) for discovering BACnet devices over BACnet/IP networks. It is designed to help users identify and list BACnet devices available on their local network.

## Features
- Discovers BACnet devices using BACnet/IP protocol
- Outputs device information for further integration or analysis

## Requirements
- Python 3.7+
- BACnet/IP compatible network
- Any required Python packages (see script for details)

## Usage
1. Ensure you have Python installed on your system.
2. Install any required dependencies (see script for package requirements).
3. Run the script:
   ```powershell
   python bacnet_device_discover_01092025.py
   ```
4. Follow the on-screen instructions to discover devices.


## Notes
- For troubleshooting or extending functionality, refer to the comments in the script.
- BACnet/IP network access is required for device discovery.
