## Getting started

1. Choose a protocol folder above and download a server/simulator plus a matching client.
2. Install any listed prerequisites (for example, .NET Framework 3.5 for legacy OPC DA tools).
3. Start the simulator, then connect the client to opc.tcp://localhost:4840 (OPC UA) or the equivalent endpoint for the chosen protocol.
4. Verify downloads using the CHECKSUMS.sha256 file in each catalog folder.

## Verification

```powershell
Get-FileHash .\<file> -Algorithm SHA256
```

```bash
sha256sum <file>
```
