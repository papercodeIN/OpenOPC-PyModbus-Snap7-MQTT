# OPC UA Modeling

## Unified Automation UaModeler 1.6.9 (build 517)

UaModeler is a graphical tool for creating OPC UA information models (NodeSet XML). Use it to extend the sample address space, then load the generated NodeSet into the [Simulation Server](../Servers/Readme.md).

On Linux, unzip the archive, make the AppImage executable and run it:
