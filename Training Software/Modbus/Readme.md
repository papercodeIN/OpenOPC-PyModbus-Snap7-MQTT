# Modbus Training Software

Modbus client (master) and server (slave) simulators, scanners, analyzers and supporting tools for training and learning. All installers are published as assets on the **[Modbus Training Tools release](https://github.com/papercodeIN/OpenOPC-PyModbus-Snap7-MQTT/releases/tag/modbus-tools-2026-11-19)**.

Download base URL: `https://github.com/papercodeIN/OpenOPC-PyModbus-Snap7-MQTT/releases/download/modbus-tools-2026-11-19/`

## Modbus Poll and Modbus Slave (Windows)

The classic pair: **Modbus Poll** acts as a master/client, **Modbus Slave** as a server/device simulator. Run both to practice register reads and writes without hardware.
